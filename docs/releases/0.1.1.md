## Download and install

**[Download Vaulto Note for Mac — DMG](https://github.com/dirusanov/vaulto-note-mac/releases/download/v0.1.1/Vaulto-Note-0.1.1.dmg)**

1. Open the downloaded DMG and drag **Vaulto Note** onto **Applications**.
2. Open **Vaulto Note from Applications**, then eject the disk image. If macOS asks whether to open an app downloaded from the internet, choose **Open**.
3. In the welcome guide, allow the microphone and open System Settings to enable **Vaulto Note** under **Privacy & Security → Accessibility**. This lets the app insert dictated text into other apps.
4. Choose your dictation key and wait for the speech model to finish downloading and preparing. Hold the key, speak, then release it to insert text.

The app and DMG are signed with an Apple Developer ID and notarized by Apple. Installation uses the standard macOS flow.

Requires **macOS 14 or later**, **Apple Silicon (M1 or newer)** and about **2 GB of free space** for the default model. Intel Macs are not supported. The speech model (about **1.6 GB**) downloads once during setup, so an internet connection is needed for the first setup; dictation then runs locally on your Mac.

If you previously denied microphone access, click the microphone permission button again to open System Settings. If you skip Accessibility, recognized text can still be copied manually. A failed model download can be retried from the welcome guide.

## What's new

- Developer ID signing and Apple notarization for the app and disk image.
- Automatic daily update checks, with manual checks from the app menu and Settings.
- Updates wait for dictation and model preparation to finish before restarting.
- Setup shows model download progress and preparation, with retry after an error.

## Updating from 0.1.0

First **quit the old Vaulto Note** from its menu, then install this DMG once and choose **Replace** when copying it to Applications. Open the new copy from Applications. Your models, history, and preferences are preserved. Because the signing identity has changed, macOS may request microphone and Accessibility permissions again. Subsequent updates are available inside the app.

The ZIP and `appcast.xml` assets are used for automatic updates; the DMG is the main installation download.

## По-русски

**[Скачать Vaulto Note для Mac — DMG](https://github.com/dirusanov/vaulto-note-mac/releases/download/v0.1.1/Vaulto-Note-0.1.1.dmg)**

1. Откройте скачанный DMG и перетащите **Vaulto Note** в **Applications («Программы»)**.
2. Запустите **Vaulto Note из «Программ»**, затем извлеките образ. Если macOS спросит, открывать ли приложение из интернета, нажмите **«Открыть»**. Приложение подписано Developer ID и одобрено Apple.
3. В мастере настройки разрешите микрофон. Для вставки текста откройте **«Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ»** и включите **Vaulto Note**.
4. Выберите клавишу диктовки и дождитесь загрузки и подготовки модели. Зажмите клавишу, произнесите фразу и отпустите — появится текст.

Нужны **macOS 14+**, **Mac с Apple Silicon (M1 или новее)** и около **2 ГБ свободного места**. Модель занимает около **1,6 ГБ** и скачивается один раз; для первой настройки нужен интернет. Затем диктовка работает локально. Mac с Intel не поддерживаются.

**Обновление с 0.1.0:** сначала завершите старую версию через меню Vaulto Note, затем скопируйте новую в «Программы» и нажмите «Заменить». Модели, история и настройки сохранятся; macOS может повторно запросить разрешения. Если загрузка модели прервётся, в мастере есть кнопка повтора. Если микрофон ранее запрещён, повторное нажатие кнопки разрешения откроет системные настройки.
